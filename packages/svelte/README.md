# @llm-ui-annotation/svelte

The annotation overlay: a Svelte 5 custom element `<annot-overlay>` with an open shadow root.

Auto-mounted by `@llm-ui-annotation/vite-plugin` in dev, or mounted by hand with `mount(options)` or `<Annotator />`.

Build setup is owned by WS 04; the theme entry under `src/theme/` is owned by WS 03.
